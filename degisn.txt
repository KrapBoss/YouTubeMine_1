# 📋 [밈 애니멀 진화 연구소] 최종 시스템 개발 명세서 (Game Design & Technical Spec)

## 1. 프로젝트 개요 (Project Overview)
* **프로젝트명:** 밈 애니멀 진화 연구소 (Meme Animal Lab)
* **장르:** 유튜브 라이브 스트리밍 연동 24시간 무인 자동화 2D 물리 머지(Merge) 게임
* **타겟 유저:** 비성인(10대 청소년 및 저연령층) 위주의 무과금 참여자 및 소액 후원자 ($1 ~ $5)
* **핵심 컨셉:** 
  * 과일 대신 잘파세대에게 친숙한 '인기 밈 동물 및 말랑 생명체' 1~10단계 진화 트리 적용
  * 시청자 다수의 '협동(구원)'을 기본 베이스로 하되, 협동보다 높은 단가의 '무적 방해물 투하(트롤링)' 후원을 배치하여 텐션과 도파민 유도
* **코어 루프 (Core Loop):**
  1. **자동 및 수동 스폰:** 5초마다 상단 크레인에서 기본 동물 자동 낙하 + 시청자 채팅 명령어로 위치 제어 및 추가 투하
  2. **물리 충돌 및 합체:** 스프라이트 외곽선을 따르는 다각형 콜라이더 기반 물리 연산 -> 동일 단계 충돌 시 상위 단계로 진화 및 후원자 닉네임 계승
  3. **시청자 개입:** 무료 이벤트(좋아요/구독) 및 유료 후원($1~$5)을 통한 협동 구원 또는 영구 방해 블록 투하
  4. **종료 및 순환:** 데드라인 10초 초과(실패 리셋) 또는 10단계 최종 동물 완성(클리어 빵빠레 및 MVP 노출 후 리셋)을 통해 24시간 무인 순환

## 2. 인게임 오브젝트 및 물리 시스템 명세 (Object & Physics System)

### 2.1. 오브젝트 데이터 구조 (`MergeObject.cs`)
* `int Level`: 오브젝트 진화 단계 (`1 ~ 10`, 트롤링 방해 블록은 `-1`로 예외 처리)
* `bool IsObstacle`: 트롤링 방해물 여부 (`true`일 경우 합체 및 어떤 후원 효과로도 파괴/소멸 절대 불가)
* `string OwnerName`: 오브젝트에 각인된 후원자/구독자 유튜브 닉네임 (일반 동물은 `""`)
* `int DonatedAmount`: 합체 시 이름 계승 우선순위 판별용 누적 후원 가치 (구독 = `0`, $1 = `1`, $2 = `2`, $3 = `3`, $5 = `5`)
* `bool IsMerging`: 동일 프레임 중복 합체 방지용 플래그

### 2.2. 다각형 콜라이더 및 물리 세팅 (`PolygonCollider2D`)
* **기능 정의:** 
  * 모든 1~10단계 동물 및 트롤링 방해물은 원형이 아닌 **스프라이트 실제 외곽선(귀, 꼬리, 모서리 등)을 따라가는 `PolygonCollider2D`**를 적용한다.
  * 물리 연산 병목 및 끼임(Tunneling) 방지를 위해 Sprite Editor의 Custom Physics Shape 정점(Vertex) 개수는 객체당 **8~12개 이내**로 단순화한다.
  * `Rigidbody2D` 설정: `Collision Detection = Continuous`, 일반 동물 `Mass = 1.0 ~ 3.0`(단계 비례), 트롤링 블록 `Mass = 5.0`.
  * `PhysicsMaterial2D` 설정: `Friction = 0.4`, `Bounciness = 0.15`.
* **역할 및 용도:** 
  * 원형 콜라이더처럼 쉽게 굴러가지 않고 귀나 턱 모양에 걸려 기하학적인 빈틈(아치형 브릿지)을 형성하게 만들어, 예측 불가능한 물리 변수와 협동 후원 아이템의 사용 당위성을 높인다.

### 2.3. 합체(Merge) 및 후원자 닉네임 계승 규칙
* **기능 정의 (`OnCollisionEnter2D`):**
  * 충돌 조건: 두 객체의 `Level`이 동일(`1 ~ 9`)하고, 둘 다 `IsObstacle == false`이며 `IsMerging == false`일 때 발동.
  * 진화 생성: 두 객체의 중점 좌표에 `Level + 1` 프리팹을 생성하고 짧은 밈 보이스/효과음 재생 후 기존 두 객체는 파괴(또는 오브젝트 풀 반환).
  * **닉네임 계승(Inheritance) 알고리즘:**
    1. 두 객체 중 한쪽만 `OwnerName`이 있으면 해당 이름을 상위 단계 동물에 그대로 계승한다.
    2. 두 객체 모두 `OwnerName`이 있으면 `DonatedAmount`가 더 높은 유저의 이름과 금액 가치를 계승한다 (금액까지 동일할 경우 먼저 생성된 객체 우선).
  * **닉네임 UI 렌더링 (`NameTagUI.cs`):**
    * 오브젝트 하위의 월드 스페이스 `TextMeshPro`는 부모 다각형 객체가 굴러가서 뒤집히더라도 항상 정방향으로 읽히도록 `LateUpdate()`에서 `transform.rotation = Quaternion.identity`로 회전값을 고정한다.
* **역할 및 용도:** 
  * 후원자 및 구독자가 소환한 동물이 다른 시청자들의 도움으로 최종 10단계까지 진화할 때 자신의 이름이 끝까지 살아남게 하여 강한 소속감과 장기 체류(리텐션)를 유도한다.

## 3. 시청자 참여 및 과금(BM) 이벤트 상세 명세

비성인 타겟에 맞춰 과금 상한선을 $5(5,000원)로 제한하며, **협동(저단가) vs 트롤링(고단가, 파괴 불가)** 구도로 동작을 정의한다.

| 분류 | 트리거 조건 | 호출 메서드 | 상세 기능 및 물리 동작 정의 | 역할 및 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **자동 스폰** | 5초 주기 타이머 | `AutoDrop()` | 상단 스포너가 좌우 왕복 이동하며 5초마다 1~2단계 일반 동물(이름 없음) 자동 낙하 | 무입력 시간대에도 방송 화면이 멈추지 않고 굴러가도록 보장 |
| **채팅 제어** | `!좌`, `!우`, `!1`~`!5`<br>`!드롭` | `MoveSpawner()`<br>`CommandDrop(user)` | • 스포너 X좌표 이동 제어<br>• 개인 쿨타임(20초) 검증 후 1~3단계 기본 동물 즉시 투하 | 결제 수단이 없는 저연령층 시청자의 100% 무료 참여 보장 |
| **무료 협동 1** | **좋아요 (Like)** | `TriggerBounce()` | 상자 바닥 또는 내부 전체 객체에 위쪽 방향 순간 물리력(`AddForce(Vector2.up * force, Impulse)`) 1회 부여 | 다각형 모서리에 걸려 정체된 동물들을 살짝 흔들어 틈새 합체 유도 |
| **무료 협동 2** | **구독 (Subscribe)** | `SpawnSubAnimal(user)` | `[구독자 닉네임]`이 각인된 **4단계 동물** 확정 스폰 (`DonatedAmount = 0`) | 무료로 자신의 이름을 중형 동물에 박제시켜 채널 구독 전환율 견인 |
| **협동 후원 1** | **1,000원 ($1)** | `ClearSmallAnimals(user)` | 상자 내 활성화된 객체 중 `Level <= 2`이고 `IsObstacle == false`인 소형 일반 동물만 일괄 폭파 삭제 *(방해물은 절대 파괴 불가)* | 다각형 틈새를 막고 있는 잔챙이들을 치워 공간을 확보하는 가성비 구원 기믹 |
| **협동 후원 2** | **2,000원 ($2)** | `SpawnRainbowStar(user)` | `[후원자 닉네임]`이 적힌 만능 별 투하. 처음 충돌한 일반 동물(`IsObstacle == false`, `Level < 10`)을 즉시 `Level + 1`로 진화시키고 후원자 이름 각인 (`DonatedAmount = 2`) | 모양 때문에 합쳐지지 않고 버티는 고단계 동물을 강제 진화시키는 타겟형 구원 |
| **트롤링 후원** | **3,000원 ($3)** | `SpawnTrollBlock(user)` | `[후원자 닉네임]`이 굵게 박힌 **절대 파괴/합체 불가 고중량 다각형 블록(`IsObstacle = true`, `Mass = 5.0`)** 투하. 해당 판 종료(리셋) 시까지 영구 존속 | 협동보다 비싼 값을 치르고 상자 공간을 영구 잠식하며 시청자들을 고통받게 하는 핵심 빌런 BM |
| **피버 후원** | **5,000원 ($5)** | `StartMagnetFever(user)` | **10초간 자석 폭풍 코루틴 실행:**<br>1. 트롤링 블록(`IsObstacle == true`)은 파괴하지 않되 외곽으로 밀어내는 물리 척력 적용<br>2. 동일 `Level`의 일반 동물끼리 서로 끌어당기는 자석 인력(`AddForce`)을 지속 적용하여 강제 연쇄 합체 발동 | 트롤링 블록의 무적 규칙을 훼손하지 않으면서도 물리적 힘으로 판을 뒤집는 최고액 하이라이트 연출 |

## 4. 게임 종료 판정 및 리셋(Reset) 시퀀스 명세

### 4.1. 실패 종료 시스템: 한계선(Dead Line) 10초 초과 (`DeadlineSensor.cs`)
* **기능 상세 정의:**
  * 상자 상단 수평 트리거(`BoxCollider2D - IsTrigger`) 내부에 일반 동물 또는 트롤링 블록이 머무르며, 해당 객체의 속도(`rb.velocity.magnitude`)가 `0.1f` 이하일 때(위에서 막 떨어지는 중이 아닐 때) 위험 상태로 감지한다.
  * 위험 상태 객체가 1개 이상 유지되면 `dangerTimer`를 증가시키고 화면 중앙에 **`10.00`초 카운트다운 UI** 및 경고음을 출력한다.
  * 10초가 되기 전에 합체나 후원 효과로 모든 객체가 한계선 아래로 내려가면 즉시 `dangerTimer = 0`으로 초기화하고 카운트다운을 취소한다.
  * **`dangerTimer >= 10.0f` 도달 시:** 즉시 스폰을 중단하고, 상자 내부의 **모든 일반 동물과 무적 트롤링 방해물을 팝(Pop) 이펙트와 함께 전부 소멸(Destroy)**시킨 뒤 3초 후 빈 상자에서 새 게임을 자동 시작한다.
* **역할 및 용도:**
  * 유튜브 송출 딜레이를 감안한 10초의 골든타임을 부여하여 위기 순간 구원 후원을 유도하고, 판이 끝나면 파괴 불가 트롤링 블록까지 깔끔하게 청소하여 24시간 무인 방송이 멈추지 않게 한다.

### 4.2. 클리어 종료 시스템: 최종 10단계 완성 빵빠레 (`GameManager.cs`)
* **기능 상세 정의:**
  * 두 개의 9단계 동물이 합쳐져 **최종 10단계 동물(`Level == 10`)이 생성되는 순간** 즉시 스폰 및 데드라인 판정을 중지하고 클리어 시퀀스 코루틴을 실행한다.
  * **빵빠레 및 기여자 노출 시퀀스 (약 8초간 진행):**
    1. 빵빠레 사운드 및 폭죽 파티클 재생, 완성된 10단계 동물을 화면 중앙으로 연출 강조.
    2. 10단계 동물에 최종 계승된 `OwnerName`(기여 후원자 닉네임)을 추출하여 화면 중앙 대형 현수막 UI에 **`"🎉 최종 완성! 기여자: [OwnerName] 님! 🎉"`** 문구를 띄워 박제한다 (`OwnerName`이 비어있을 경우 `"시청자 협동 클리어!"` 출력).
    3. 8초간의 세리머니 종료 후, 상자 내 모든 동물과 트롤링 방해물을 일괄 소멸시키고 빈 상자에서 다음 판을 자동 재시작한다.
* **역할 및 용도:**
  * 협동 후원에 참여한 유저에게 전 시청자 앞에서 이름이 박제되는 명예 보상을 제공하여 다음 판의 반복 참여를 유도한다.

## 5. 유니티 프로젝트 폴더 및 스크립트 아키텍처 (Directory Structure)

```text
Assets/Scripts/
 ├── Core/
 │    ├── GameManager.cs          // 게임 상태(Playing, Clear, GameOver), 클리어 빵빠레 및 전체 리셋 제어
 │    ├── Spawner.cs              // 상단 크레인 이동, 5초 자동 낙하, 구독/후원 특수 오브젝트 스폰
 │    └── DeadlineSensor.cs       // 상단 한계선 체류 감지, 10초 카운트다운 타이머 및 실패 트리거
 ├── Data/
 │    └── AnimalStageDataSO.cs    // 1~10단계 동물 및 트롤링 블록의 스프라이트, 스케일, 질량(Mass) 데이터 컨테이너
 ├── Objects/
 │    ├── MergeObject.cs          // PolygonCollider2D 물리 객체, 동일 단계 합체 연산, 후원자 이름/금액 계승

 ├── Effects/
 │    └── FeverController.cs      // 좋아요 바운스, $1 잔챙이 청소, $5 10초 자석 폭풍(인력/척력) 물리 제어
 └── Network/
      └── YouTubeEventReceiver.cs // 유튜브 라이브 채팅/좋아요/구독/슈퍼챗 이벤트를 수신하여 인게임 큐에 전달



# UI
html의 모달 구조 사용.
리소스(resources)를 통해 불러오고 생성, 삭제밖에 없음
UI는 임의의 스크립트 제작만 진행
별도의 order 조절을 안함

# 메인 UI
좌 상단 : 사용자 이벤트를 1열 리스트 형식으로 표시 "아이콘 : 텍스트" (아이콘은 클라이언트가 직접 대입할 것)
우 상단 : 후원자 목록 5명 , 후원 금액 순으로 정렬 "아이콘 : 텍스트" (아이콘은 클라이언트가 직접 대입할 것)
중앙 : 후원이나 구독 등 이벤트가 발생할 경우, 화면 전체를 활용하는 '전면 이벤트 연출(예: 힌트 자동 폭발, 마법 조각 투하, 대형 빵빠레)'이 화려하게 출력되는 다목적 공간
